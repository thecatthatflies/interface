The idea

Every interface now has two readers: a person looking at pixels and an agent reading the accessibility tree. The mark is a focus ring, the one piece of an interface drawn for readers who do not point.

Exact

Real numbers, named sources, rules tagged by evidence. Nothing promotional.

Humane

Plain words for people; the tree and the code are shown, not hidden.

Institutional

Borrowed from guideline manuals: grids, numbered rules, monospace notes.

Why the mark looks like this

A focus ring around a control: drawn for keyboard, switch and screen reader users, and the same element an agent targets. Thick ring, real hole, solid center, so it holds at 16 px and in one color.

Logo

Use the files as supplied. The lockup leads; the mark stands alone only where space is square or tiny.

Clear space

Keep at least the height of the mark’s smallest counter, about 25% of the logo height, free of other elements on every side.

Do not

Color

Every color is a role first and a value second. Build with the roles; the ramps exist for the rare case a role does not cover.
